# TalkEcho v0.2.3

## Windows dictation

- Keep the same Right Ctrl routing decision for the entire press, including repeats and release. When the worker cannot accept the first key-down, the full press is forwarded.
- Keep the current hook responsible for a held press during renewal. A temporary release guard allows a genuine key-up to reach the existing hook chain and can recover stale local tracking.
- Software-injected Right Ctrl events pass through. Keyboard macros that previously used these events to toggle dictation will need another trigger.

## Diagnostics

- Record Right Ctrl routing, hook renewal, release recovery, and the foreground window handle and process ID in the bounded local dictation log.
- The webview reports structured lifecycle events. Raw transcripts, cleaned output, and provider error bodies are excluded from the dictation lifecycle logs and terminal output.

## Validation

- The Windows validation passed 38 frontend tests, 32 native tests, and the production frontend build. Native tests cover press routing, dispatch failures, hook handoff, and rejection of free-form diagnostics.
- Historical desktop smoke runs used tagged synthetic input. Acceptance with a physical keyboard in windowed and fullscreen Remote Desktop, including focus changes, remains pending. Issue #70 remains open.
- The release executable started on Windows, installed its hook, and logged the webview's structured synchronization event. The NSIS archive and 64-bit MSI metadata were verified. Installation and physical-key tests remain pending.

## Windows downloads

- `TalkEcho_0.2.3_x64-setup.exe` – Windows x64 NSIS installer.
- `TalkEcho_0.2.3_x64_en-US.msi` – Windows x64 MSI installer.
- `SHA256SUMS.txt` – SHA-256 checksums for the two installers.

Close TalkEcho before installing either package. These local packages are unsigned, so Windows may show an unknown-publisher warning. Updater signatures are disabled for this manual-install release.
