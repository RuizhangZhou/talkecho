# TalkEcho v0.2.0

This is a substantial Windows desktop update focused on a calmer background workflow, safer provider credential handling, and more usable conversation content.

## Highlights

- **Tray-resident workflow:** hide the TalkEcho main bar when it is not needed and bring it back with the tray icon. The tray context menu provides Dashboard and Quit actions; the icon tooltip reflects recording state.
- **Better dictation reliability:** dedicated speech-to-text provider and language settings, plus Right Ctrl hotkey and startup-timing improvements.
- **Copy the content that matters:** select and copy meeting transcripts, questions, answers, AI responses, and Dashboard Markdown directly from the app.

## Security upgrade

Provider API keys are now stored in the operating-system credential manager rather than in WebView localStorage. TalkEcho migrates supported existing configurations on startup, and cURL templates retain `{{API_KEY}}` plus an opaque credential reference instead of the secret itself.

**After updating, rotate every provider API key that was previously used with TalkEcho.** Migration protects the active profile going forward, but cannot remove plaintext copies that may already exist in backups, synchronized folders, logs, or other historical data.

Credentials normally remain in the operating-system credential manager after an uninstall/reinstall. Delete a key in TalkEcho before uninstalling if it should not be retained.
